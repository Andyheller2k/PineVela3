**How does System default work?** It follows the browser/phone's theme, including later changes. Explicit Light or Dark uses the saved choice instead. The public landing switch has Light/Dark only.

Avoid FAQ promises that every property is risk-free, every merchant is honest, all messages are encrypted including support, a refund is automatic, or an app alert is emergency assistance. Link approved policy text instead of creating contradictory answers.
