# PineVela login concepts — 26 October 2026

Five generated visual concepts for choosing a design before implementation.
Each board shows Login and Sign Up side by side, using PineVela's existing girl
artwork above the form. The fifth option adds the requested blurred transition.
These are concept pictures; the login page code has not been changed.

| 3 | [Golden arch](03-golden-arch.png) | Broad gold transition around an inset navy card |
| 4 | [Layered wave](04-layered-wave.png) | Yellow/blue ribbons above a glass form card |
| 5 | [Blur transition](05-blur-transition.png) | Soft navy fade from artwork into the form |

Created with the built-in image generation tool. Original images remain in the
tool's generated-image directory; these workspace copies are not used by the app.
The [prompt set](prompts.md) records the reference roles and design directions.
